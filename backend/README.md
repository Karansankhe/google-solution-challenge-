# Swasthya Mitra Backend

This repository contains the backend service for **Swasthya Mitra**, a secure agentic intelligence platform built with **FastAPI** and the **Gemini API**. It provides an advanced suite of tools for health surveillance, supply chain distribution planning, and interactive chat.

## Features

- **Agentic AI Pipeline**: Powered by the Gemini API and agent frameworks like Agno, it coordinates multiple AI agents (e.g., Signal Collectors, Festival Surge Anticipators, and Pollution Risk Agents) to formulate health intelligence reports.
- **Proactive Health Surveillance**: Aggregates localized data including geocoding, real-time weather and AQI parameters, and health news to forecast health risks.
- **Supply Chain Redistribution**: Uses surveillance intelligence and primary healthcare center (PHC) datasets to proactively generate optimized resource distribution and supply chain plans.
- **Serverless Ready**: Fully configured and compatible for deployment on Vercel using its Python runtime.
- **Secure**: Implements API key validation for restricted endpoints.

## API Endpoints Overview

The application features three main routers under the `/api/v1` namespace.

### 1. Root & Health
- **`GET /`**
  - **Description**: Root endpoint that welcomes you to the project.
- **`GET /api/v1/surveillance/health`**
  - **Description**: Returns the current health status and timestamp of the surveillance API.

### 2. Surveillance (`/api/v1/surveillance`)
This module is responsible for analyzing locations and generating structured health intelligence reports.
- **`GET /geocode`**
  - **Description**: Resolves a string location to geographical coordinates (lat, lon).
- **`GET /snapshot`**
  - **Description**: A lightweight endpoint that returns only a snapshot of the current weather, AQI, and health news for a given location, bypassing the AI agents.
- **`POST /analyze`**
  - **Description**: Runs the full 3-agent health surveillance cycle for a given location (e.g., Signal Collector, Surge Anticipator, Pollution Agent). It synthesizes all signals into a structured JSON intelligence report and securely saves it in a temporary environment for downstream tasks.
- **`POST /analyze/stream`**
  - **Description**: A streaming version of the analyze endpoint that leverages SSE (Server-Sent Events) to return the progress of the agents in real-time, followed by the final report.

### 3. Distribution (`/api/v1/distribution`)
This module handles forecasting and supply chain planning based on surveillance intelligence.
- **`POST /plan`**
  - **Description**: Generates a proactive distribution and resource redistribution plan. It requires the `surveillance` module to have successfully run an analysis first (reading the temporary file generated by `/analyze`). It coordinates Resource Forecasting and Supply Chain agents.

### 4. Chat (`/api/v1/chat`)
- **`POST /chat`**
  - **Description**: An interactive chat endpoint that relies on the Gemini API to converse with the user or provide general health intelligence insights. *Secured via API Key dependency.*

## Deployment

This backend is designed for Vercel using the `@vercel/python` builder. The provided `vercel.json` maps all requests dynamically to the FastAPI application inside `app/main.py`. Since Vercel Serverless Functions are stateless, inter-agent data passing (like the surveillance report passing to the distribution planner) utilizes the `tempfile` module to access `/tmp`.

### Local Setup
1. Create a `.env` file based on `.env.example`.
2. Install requirements: `pip install -r requirements.txt`.
3. Run the application: `uvicorn app.main:app --reload`.
